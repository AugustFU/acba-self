# Acba Self

Неофициальный, но удобный просмотр состояния счета в ACBA Bank: баланс, история операций, траты за месяц и курсы валют.
> Перед развёртыванием прочитайте пункт про безопасность. Приложение работает с логином, паролем и одноразовым кодом от банка, и стоит понимать, через что они проходят.

## Что умеет

- **Доступный баланс** в ֏ с пересчётом в ₽, а под ним остаток по выписке и сумма операций в статусе pending.
- **Траты за месяц**: столбики по дням, средняя трата в день, прогноз до конца месяца, разбивка по категориям. Нажатие на категорию фильтрует историю, нажатие на столбик показывает траты за этот день.
- **История операций** одним списком по дням: проведённые операции и операции в обработке (отмечены часиками). Есть поиск, а нажатие на операцию открывает подробности.
- **Курсы валют** банка (карта, безнал, наличные) и курс ЦБ, плюс конвертер ֏ ⇄ ₽, $, € и другие валюты.

## Как это работает

Сервис на Cloudflare Worker проксирует запросы до Acba Bank. Он отдаёт саму страницу приложения и пересылает в банк шесть разрешённых запросов. Всё остальное он отклоняет.

    Acba Self -- HTTPS --> Cloudflare Worker -- HTTPS --> API ACBA Bank

Worker работает только с этими запросами:

| Запрос | Ответ |
|---|---|
| `Authorization/AuthorizeByPassword` | проверка логина и пароля |
| `Authorization/AuthorizeByToken` | проверка одноразового кода OTP, выдача ключа доступа |
| `HomePage/GetCards` | карта: тип, последние цифры, валюта |
| `Card/GetCardStatement` | выписка |
| `Card/GetPendingTransactions` | операции в обработке |
| `rates/getrates` | курсы валют |

Весь проект собирается в один файл `dist/worker.js`: внутри код Worker’а, страница приложения, манифест и иконки. Ещё Worker отдаёт по адресу `/version` номер сборки

## Структура репозитория

```
app.html             страница приложения
worker.template.js   код Cloudflare Worker’а
build.py             сборка: склеивает всё в dist/worker.js
assets/logo.png      логотип для иконки
assets/otp-help.png  картинка с подсказкой OTP
dist/worker.js       готовый файл для Cloudflare
README.md            эта инструкция
```

Редактировать нужно `app.html`, `worker.template.js` и картинки в `assets/`. Файл `dist/worker.js` собирается из них.

## Развёртывание

### через Cloudflare

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com). Хватит бесплатного тарифа.
2. Откройте раздел **Workers & Pages**, нажмите **Create** и выберите Worker из шаблона «Hello World». Задайте имя, например `acba`, и нажмите **Deploy**.
3. Нажмите **Edit code**, удалите весь код из редактора, вставьте содержимое `dist/worker.js` и снова нажмите **Deploy**.
4. Адрес приложения будет вида `https://acba.<ваш-аккаунт>.workers.dev`. Он показан на странице Worker’а.

### Пересборка после изменений

Если вы меняли `app.html`, `worker.template.js` или картинки в `assets/`, соберите файл заново и разверните его:

```bash
pip install pillow
python3 build.py
```
Скрипт создаст новый `dist/worker.js`. Номер версии иконки считается из её содержимого, поэтому при смене логотипа iPhone увидит новую иконку, а не старую из кэша.

## Установка на iPhone

1. Откройте адрес Worker’а в **Safari**.
2. Нажмите кнопку «Поделиться», выберите **«На экран „Домой“»** и нажмите **«Добавить»**.
3. Запускайте приложение с иконки: оно откроется во весь экран, без адресной строки.

## Вход

Вход повторяет вход в Acba Digital:

1. **Логин и пароль** — те же, что в Acba Digital.
2. **Код OTP.** Откройте мобильное приложение Acba Digital, на экране входа нажмите кнопку «OTP» и введите показанный код. Подсказка со скриншотом есть прямо на экране входа.
3. **Номер карты** — только при первом входе. Для выписки банк требует полный номер карты, а в списке карт отдаёт только последние 4 цифры. Приложение проверяет номер по контрольной сумме и по последним цифрам и запоминает его на телефоне.

### Сессия

Ключ доступа от банка действует около часа. Пока он жив, приложение при открытии сразу показывает данные и обновляет их, если им больше 90 секунд. Обновить вручную можно нажатием на «Обновлено в …» в правом верхнем углу.

Когда ключ истёк или банк его отозвал (например, после входа в Acba Digital на другом устройстве), приложение сразу открывает форму входа поверх последних загруженных данных. Логин подставляется сам, а пароль и код OTP нужно ввести заново. Кнопка «Не сейчас» закрывает форму и оставляет данные с плашкой «Войти».

### Пароль по Face ID

Форма входа размечена как стандартная (`autocomplete="username"` и `current-password`), поэтому iPhone может хранить пароль в Связке ключей iCloud и подставлять его по Face ID, как в настоящем приложении банка.

1. Один раз войдите в приложение. После нажатия «Продолжить» iPhone предложит сохранить пароль — согласитесь.
2. Если предложение не появилось (на экране «Домой» iOS показывает его не всегда), добавьте пароль вручную: приложение **Пароли** (или Настройки → Пароли) → «+» → в поле «Сайт» адрес Worker’а, например `acba.<ваш-аккаунт>.workers.dev`, затем логин и пароль от Acba Digital.
3. В следующий раз нажмите на поле пароля: над клавиатурой появится сохранённый пароль, подтвердите его Face ID.

Код OTP всё равно нужно брать в приложении Acba Digital при каждом входе — так устроена защита банка.

## Как батракан считает циферки

- **Период истории** — с 1-го числа прошлого месяца по сегодня, плюс все операции в обработке. Поэтому в блоке «Траты за месяц» можно листать только текущий и прошлый месяц. Период задаёт настройка `monthsBack` в начале кода в `app.html`.
- **Доступный баланс.** Банк в списке карт отдаёт баланс `0`, поэтому приложение считает его само: остаток по выписке минус операции в обработке на списание плюс операции в обработке на зачисление.
- **Рубли** пересчитываются по курсу ЦБ из ответа банка (`CB` для `RUR`).
- **Категории** (продукты, транспорт, такси и т. д.) приложение угадывает по названию операции. Правила лежат в `CATEGORY_RULES` в `app.html`, а понятные названия для известных мест — в `NAME_ALIASES`.

## Что хранится на телефоне

Данные лежат в хранилище браузера (localStorage) на этом устройстве:

| Ключ | Что внутри | Удаляется при выходе |
|---|---|---|
| `mybank.session.v2` | ключ доступа от банка и время его окончания | да |
| `mybank.cache.v2` | последняя загрузка: карта, выписка, операции, курсы | да |
| `mybank.user.v2` | логин | нет |
| `mybank.pan.v2` | полный номер карты | нет |
| `mybank.prefs.v2` | выбранный тип курса и режим скрытия сумм | нет |
| `mybank.installHint.v2` | скрыта ли подсказка про экран «Домой» | нет |

Пароль и код OTP не сохраняются нигде: ни на телефоне, ни в Worker’е.

## Безопасность
| # | Risk | Severity | Solution |
|---|---|---|---|
| 1 | Cloudflare Worker видит пароль, код OTP и ключ доступа в открытом виде | high | 2FA на аккаунте Cloudflare, никому не давать доступ, передача своих данных Cloudflare |
| 2 | Адрес Worker’а открыт всему интернету и может использоваться как ретранслятор к банку | high | Cloudflare Access перед Worker’ом |
| 3 | На телефоне в открытом виде лежат выписка, номер карты и логин | medium | код-пароль на телефоне, полная очистка при выходе |
| 4 | Использование неофициального API и входы с адресов Cloudflare | medium | регулируется пользовательским соглашением Банка |

## Ограничения

- Это неофициальный клиент. **Использовать на свой страх и риск**.
- Поддерживается одна карта — первая из списка банка.
- Только чтение: переводов, платежей и управления картой нет.
